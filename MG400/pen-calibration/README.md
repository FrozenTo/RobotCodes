# MG400 pen calibration

- `mg400_r_angle_calibration.py`: R-angle line test.
- `mg400_radius_calibration_arc.py`: pen offset/radius arc experiment.
- `mg400_vertical_r_overlap_calibration.py` and `_v2.py`: vertical overlap tests.
- `mg400_writer.py`: unchanged extra local copy to satisfy imports.
- `alternate-upload-copies/`: old upload copies preserved.

These are physical motion experiments: review limits, fixtures, TCP offsets and current robot calibration before running.
