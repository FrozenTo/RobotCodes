# xArm 850 wall text writer

Early, v2 and v3 versions of `uf850_wall_writer.py` and `uf850_wall_writer_app.py` are kept **next to their corresponding versioned core** so the GUI imports work.

- Main directory: writing core and GUI iterations (`uf850_wall_writer[_v2|_v3].py`, matching `_app` scripts).
- `legacy-versions/`: older unversioned core/app pair from the original `old movements` folder.
- `alternate-upload-copies/`: other uploaded files (some exactly identical, others historical).
- `archive-compiled/`: preserved bytecode only.

Do not infer that the largest number is physically tested or that historical wall TCP offsets are still correct.
