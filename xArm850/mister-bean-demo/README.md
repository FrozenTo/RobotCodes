# xArm Mister Bean standalone drawing demo

The `xarm_850_mister_bean_standalone_demo.py` program embeds its drawing directly in the Python source and is accompanied by `README_Mister_Bean_Demo.md`.

The separate `mister_bean_color_compatible.json` is a reusable example JSON freehand drawing and is filed under `../freehand-drawing/example-drawings/`; it is **not a runtime requirement** of this standalone program.
